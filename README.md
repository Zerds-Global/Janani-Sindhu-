# Happy Birthday, Janani Sindhu 💜
A 15-section interactive birthday website. Plain HTML, CSS and JavaScript, with no install and no internet needed.

**Run:** unzip and double-click `index.html` (or run `npx serve .` / `python3 -m http.server`).

Progress is saved in your browser (localStorage). Sound is off by default; use the speaker button (top right).
